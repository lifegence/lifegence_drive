# Security Policy

## Supported versions

Only the latest commit on the `lifegence` branch receives fixes. Upstream
[frappe/drive](https://github.com/frappe/drive) is archived and no longer fixed.

## Reporting a vulnerability

Please do not open a public issue. Report it privately in either of these ways:

- GitHub: the **Security** tab of this repository → **Report a vulnerability**
- Email: masakazu.nomura@lifegence.com

Include the affected version or commit, the steps to reproduce, and the impact you expect.
We will acknowledge the report within 5 business days and agree on a disclosure date with you.

If the issue is also present in [Frappe Suite](https://github.com/frappe/suite) or Frappe
Framework, please report it to security@frappe.io as well.
